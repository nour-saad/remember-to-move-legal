# Publish the privacy page

Published by nour-saad. Verified September 26, 2026: HTTP 200 and content matches index.html.
Review index.html before publishing; it describes the current app implementation.

1. On GitHub, create a new public repository named remember-to-move-legal.
2. Initialize with a README so a main branch exists.
3. Add file > Upload files: upload ONLY index.html from this folder to the repository root and commit.
4. Repository Settings > Pages > Build and deployment > Deploy from a branch.
5. Select main and /(root), then Save. Wait for the Pages deployment to finish.
6. Open the URL shown by GitHub in a private browser window; verify it needs no login.
